What is an API?

An API is like a door with rules. You knock in a specific way (send a request), and you get specific information back (a response). This API gives you data about stocks, weather, science, and more — all through simple web requests.

🔑

What is an API Key?

An API key is like a private pass. It tells the door who you are. You get one for free below — just give it a name and click Generate. Include it in every request so the API knows it's you.

🚀

How Do I Start?

1. Get your free API key below. 2. Pick any endpoint that interests you. 3. Click "Try it Live" on any card to test it right here. 4. Copy the code into your own project. That's it — you're building!

All endpoints use GET · Include X-API-Key header · Rate limit: 100 requests/day per key

cURL

      

      
const res = await fetch('https://www.alexnavada.xyz/api/v1/stock-quote?symbol=AAPL', {
  headers: { 'X-API-Key': 'nav_your_key_here' }
});
const data = await res.json();
console.log(data);

      
import requests

res = requests.get(
    'https://www.alexnavada.xyz/api/v1/stock-quote',
    params={'symbol': 'AAPL'},
    headers={'X-API-Key': 'nav_your_key_here'}
)
print(res.json())

      
curl -H "X-API-Key: nav_your_key_here" \
  "https://www.alexnavada.xyz/api/v1/stock-quote?symbol=AAPL"

      
Windows PowerShell: use curl.exe instead of curl
