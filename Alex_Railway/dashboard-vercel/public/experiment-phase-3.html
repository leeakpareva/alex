Phase 3 2026

Dynamic Compensation

Compensation models shift from fixed monthly salaries to reward efficiency and measurable output. High performers earn more. The data is transparent.

Traditional vs Dynamic

Traditional

100% Fixed Salary

Pay based on role, tenure, and negotiation. No direct link to output.

Dynamic

60% Base + 40% Variable

Base salary for stability. Variable component tied to measurable AI-assisted output.

Compensation Models

1

Base + Performance

60% guaranteed base salary + 40% tied to token efficiency, task completion, and quality scores. Most gradual transition.

2

Pure Value-Based

Compensation directly proportional to measured output value. Highest earning potential for top performers. Requires mature metrics.

3

Team Pool Model

Team shares a compensation pool. AI metrics determine individual allocation within the team. Encourages collaboration.

Example Calculation

Monthly Compensation Example

Base Salary $4,000
60% of $6,667 target guaranteed
Performance Multiplier 1.3x
Based on efficiency score data-driven
Variable Component $2,667 × 1.3 = $3,467
Total Monthly Pay $7,467

High performers earn 12% above target. Low performers still receive full base salary.

Transition Strategy

Pilot (Q1)

Pilot

Select volunteer teams. Run parallel tracking: old compensation + new metrics.

Hybrid (Q2)

Hybrid

Introduce 10% variable component. Demonstrate correlation between metrics and value.

Expansion (Q3-Q4)

Expansion

Increase variable to 25-40%. Refine metrics based on pilot feedback.

Standard (Year 2)

Standard

Full dynamic compensation as the default model for AI-augmented roles.
