Understanding Token Economics

Token

The atomic unit of AI processing. Every word, number, and punctuation mark is broken into tokens that the model processes sequentially.

"Hello, world!" = 4 tokens
"Supercalifragilistic" = 5 tokens
Input Tokens

Tokens sent to the model as context — your message, system prompt, conversation history, and any attached documents.

system_prompt: ~800 tokens
user_message: ~50 tokens
conversation: ~2,000 tokens
Output Tokens

Tokens generated by the model in response. These are 3-5x more expensive than input tokens because they require sequential computation.

short_reply: ~100 tokens ($0.0015)
full_analysis: ~2,000 tokens ($0.03)
Context Window

The maximum number of tokens a model can process in a single request — including both input and output. Larger windows allow richer context.

Claude Sonnet: 200K tokens
GPT-4o: 128K tokens
DeepSeek: 64K tokens
How AI Inference Works
STEP 01
Input Processing

Your message is tokenized, combined with system context, and formatted for the model.

STEP 02
Inference

The model processes all tokens through billions of parameters, generating a probability distribution for each output token.

STEP 03
Output Generation

Tokens are decoded back into readable text, streamed to the user, and logged for analytics.

Key Insight

Output tokens cost 3-5x more than input tokens because each output token must be generated sequentially, requiring a full forward pass through the model. Input tokens can be processed in parallel. This asymmetry is the foundation of token economics.

Understanding Rate Limits

Requests Per Minute (RPM)

Maximum number of API calls allowed per minute. Exceeding this triggers HTTP 429 responses and automatic retry with exponential backoff.

Impact: Queue latency, request throttling
Tokens Per Minute (TPM)

Total token throughput allowed per minute across all requests. Long context conversations consume this budget quickly.

Impact: Context window utilisation, conversation length
Tokens Per Day (TPD)

Daily token budget across all operations. Critical for capacity planning — determines how many tasks the agent can handle in 24 hours.

Impact: Daily throughput ceiling, cost projections

Calculating AI Investment ROI

Cost Formula
total_cost = (input_tokens * input_price) + (output_tokens * output_price) + infrastructure_cost // Example: 1M input + 200K output // Sonnet: (1M * $3) + (200K * $15) = $6.00 // Haiku: (1M * $0.25) + (200K * $1.25) = $0.50
Value Formula
roi = (value_generated - total_cost) / total_cost * 100 // If AI generates $500 in value // At $50/month cost: // ROI = ($500 - $50) / $50 * 100 // ROI = 900%
